# 手动验收清单

当前尚未执行以下真机验收。请在 Intel 和 Apple Silicon Mac 上分别记录 macOS 版本、应用版本和结果。

## 安装与权限

- [ ] Universal 二进制包含 arm64 / x86_64，并在两类 Mac 上原生启动。
- [ ] 从 GitHub 下载并安装的 `.app` 在未授权、已授权和已有配置三种情况下均能显示设置窗口，启动时不会崩溃。
- [ ] 首次启动未授权时有明确引导，普通鼠标操作不受影响。
- [ ] 授予辅助功能后自动开始监听；撤销权限后停止并展示正确状态。
- [ ] 关闭设置窗口后菜单栏仍可重新打开设置、暂停、恢复和退出。
- [ ] 重启应用后保留开关、绑定、快捷键、最短长度、轨迹开关和排除应用。

## 鼠标与识别

- [ ] Finder、Safari 和文本编辑器的普通右键点击仍弹出菜单；轻微抖动不触发手势。
- [ ] 自行录制的直线、二至四段折线均可识别，长短 / 快慢绘制行为一致。
- [ ] 斜线、圆圈、乱划和短拖拽不关闭窗口，也不弹出菜单。
- [ ] 移动时只显示轨迹；按住右键停顿约 200ms 后显示匹配提示，继续移动立即隐藏。松开后轨迹和提示一起清除并执行动作；普通右键点击和取消不显示提示。
- [ ] 首次绘制时浮层不闪空白帧；停顿提示出现后，不足 3 点的轻微手抖不让提示反复消失、重现，累计移动达到 3 点后隐藏提示并重新等待 200ms；单行和多行文字均垂直居中。
- [ ] Esc、其他按键或左键取消；之后右键立即恢复正常。
- [ ] 先按 Option 再按右键时，整个右键拖拽过程保持原生行为。
- [ ] 排除的前台应用完全保持原生右键行为。
- [ ] 绘制期间切换应用、暂停、进入睡眠或切换登录用户，不执行过期动作。

## 中键与前进、后退侧键

- [ ] 新安装或从旧版升级后，未绑定的中键、前进键和后退键保持原功能，已有手势配置保留。
- [ ] 三个按键分别录入不同快捷键，在目标应用中点击只执行对应动作一次，不同时触发原生动作；长按不重复，拖动超过 6 点后松开不执行。
- [ ] 测试普通五键鼠标及侧键编号不同的鼠标；“识别按键”在设置窗口内录入实际按键，前后键互换后各行快捷键保持不变，重启后保留。
- [ ] 快捷键录制时不触发目标软件；Esc、取消、切换窗口、关闭设置、切换录制项目后正确结束，旧绑定保留。
- [ ] 清除单行后恢复该按键原功能；全局重置清除三个按键的快捷键和识别结果。
- [ ] 总开关关闭、目标应用被排除或正在录制手势时，按键保持原功能；重新启用后恢复绑定。
- [ ] 按下与松开之间切换应用、桌面、暂停、清除绑定或休眠，不执行过期快捷键；随后新点击正常。
- [ ] 同时操作右键与侧键，不残留轨迹、不吞掉未绑定按键、不重复执行动作；普通右键手势仍正常。
- [ ] 最小窗口宽度、深浅色模式及 VoiceOver 下，三行按键名称、快捷键、操作按钮和录制提示完整可用。

## 功能列表与手势录制

- [ ] 列出六类共 60 项常用功能，新用户各项显示“录制手势”，旧用户已有绑定保留。
- [ ] 功能、快捷键、手势在一行按顺序显示，已录制手势以箭头显示，点击可以重录。
- [ ] 搜索与分类能筛选功能；切换筛选会取消未保存的录制并恢复监听，无匹配时有明确提示。
- [ ] 内置功能快捷键为只读文本，点击不会进入录制或修改配置；自定义快捷键仍可录入和编辑。
- [ ] 关闭窗口行显示“窗口关闭按钮”；访达功能在其他应用中不执行并提示先切换访达。
- [ ] 各功能均可在录制区域按住右键绘制、预览、保存，录制期间不触发系统动作。
- [ ] 重复手势提示占用的功能并禁止保存；短轨迹、斜线、超出录制区域的轨迹不能保存。
- [ ] 重新录制后旧手势失效，清除后不再触发，重启后保留结果。
- [ ] Esc、取消按钮、关闭窗口、切换应用取消录制，保留原绑定并恢复正常监听。
- [ ] 鼠标手势录制与键盘快捷键录制互斥，切换录制功能不残留上一次的待保存结果。
- [ ] 暂停手势或未授权时仍可录制；启用并授权后能正常触发已保存的手势。

## 自定义功能

- [ ] 没有自定义功能时，“自定义”默认显示一个空白行，标题最右侧“＋”可连续追加行，默认空白行不暂停监听。
- [ ] 多行分别录入快捷键和手势，切换行不串写；保存或取消某行保留其他草稿，已有自定义功能时，全部保存或删除空白草稿后不再补回空白行；重开设置和重启应用也不会补回。
- [ ] 删除全部已保存自定义功能后，若没有其他草稿，恢复一个默认空白行。
- [ ] 新增和编辑区域按“名称输入框、快捷键、手势、保存”单行显示，列宽与下方列表一致；浅色、深色及最小窗口宽度下无裁切。
- [ ] 点击手势才展开画板，成功后收起并在行内显示；冲突或无效轨迹保留画板并提示，可重新绘制。
- [ ] 编辑中的每行最右侧只有“保存”和“删除”两个文字按钮，最小窗口宽度下文字完整可见，不显示省略号；填写名称、录入软件快捷键、录制手势后才能保存，保存前不触发、不改写旧配置；“删除”仅放弃该行草稿。
- [ ] 保存后的每行最右侧直接显示“编辑”“清除手势”“删除”三个文字按钮，不显示省略号或隐藏菜单；编辑可修改并重新保存，删除确认后仅移除对应条目，清除手势保留名称和快捷键。
- [ ] 默认 840 点窗口及最小 760 点窗口下，自定义功能全部操作按钮和内置功能“清除”按钮文字完整可见，各列不重叠。
- [ ] 保存后保持当前分类和搜索条件，不自动切换到自定义分类；在“全部功能”下，新增条目与系统功能同时显示，名称、快捷键、手势在同一行，重启后保留。
- [ ] 自定义与内置功能之间、两个自定义功能之间的重复手势均禁止保存，提示占用者。
- [ ] 同名自定义功能、空名称、缺少快捷键或无效手势不能保存。
- [ ] 编辑修改名称、快捷键和手势后保存，旧手势失效；取消和切换窗口不会改写原配置。
- [ ] 清除手势保留名称与快捷键；删除移除条目与绑定；重置清除手势但保留自定义名称和快捷键。
- [ ] 测试目标软件的普通快捷键及全局快捷键；手势提示和最近操作显示自定义名称，录制期间不发送快捷键，结束后恢复监听。
- [ ] 保持目标软件运行，录入其全局快捷键时不触发目标功能，松开主键后显示正确组合；长按只录入一次。
- [ ] 取消、切换窗口、关闭设置和切换录制行后键盘恢复正常；未授权或拦截器创建失败时提示失败，不假装开始录制。
- [ ] 单独 Esc 取消快捷键捕获；带修饰键的 Esc 和 F13–F20 可以录入；退出编辑后普通键盘输入正常。

## 系统动作

- [ ] 创建两个以上桌面，左右切换正常；位于边缘时不触发其他动作。
- [ ] 显示桌面、调度中心在系统快捷键匹配时可触发。
- [ ] 桌面空白处绘制左右桌面、聚焦搜索和截屏手势，无需激活普通窗口；表情输入、当前应用窗口等功能仍作用于起点应用。
- [ ] 目标应用忙碌时，按下右键及普通右键菜单不等待辅助功能查询；窗口操作松开后执行一次，查询期间 Esc、点击、新手势或应用切换均可取消。
- [ ] 查询期间窗口移动、关闭或被同位置的新窗口替换，不对错误窗口执行操作；后台目标应用主动激活不误取消自身手势。
- [ ] 后台应用及带工具面板的应用中，窗口快捷键正确聚焦起点窗口；延迟激活、无法聚焦和等待中取消都有明确结果。
- [ ] 连续两次“显示桌面”手势：第一次隐藏窗口，第二次在桌面空白处绘制后窗口归位；重复切换不先激活窗口再把窗口隐藏。桌面无普通窗口时，“关闭窗口 / 标签页”不误操作后台窗口。
- [ ] 修改系统快捷键后，在应用中重新录制可以恢复对应操作。
- [ ] Safari 多标签页中，关闭标签页只关闭当前标签页。
- [ ] 关闭窗口操作针对当前前台窗口，不退出整个应用。
- [ ] 未保存文稿保留系统保存确认；未暴露关闭按钮的应用显示错误。
- [ ] 切换前台应用后不关闭新的应用窗口。

- [ ] 深浅色模式、VoiceOver、键盘 Tab 导航、设置窗口缩放正常。
- [ ] 休眠唤醒、锁屏返回后，右键不会被卡住，轨迹覆盖层不会残留。
- [ ] 长时间绘制和高轮询率鼠标下无明显卡顿，普通右键菜单行为可接受。

## 输入性能与后台开销

- [ ] 在“全部功能”分类下连续输入、删除、粘贴自定义名称；中文输入法组合、候选词上屏、方向键移动光标不丢字、不跳焦点。
- [ ] 同时打开多个自定义草稿，编辑任意行后立即保存，名称使用最后输入的内容，其他行不变。
- [ ] 暂停或未授权时，名称编辑及本地手势录制不被权限检测打断。
- [ ] 暂停手势后，菜单与设置均显示已暂停；右键行为正常。再次启用后恢复手势。
- [ ] 从辅助功能设置返回应用，立即更新权限状态；授权等待期间仍能自动开始监听。
- [ ] 休眠、锁屏、切换用户后返回，监听恢复，不重复执行动作、不残留轨迹。
- [ ] 高轮询率鼠标连续绘制时轨迹跟随鼠标，仅停顿约 200ms 后匹配和显示文字；重复上报相同位置不延后提示，松开、Esc、切换桌面后旧任务不再绘制。
- [ ] 使用 Instruments 的 Time Profiler / Energy Log 对照相同场景：设置页连续输入、后台空闲、暂停、高频绘制；区分应用 CPU 开销与整机耗电，记录设备、屏幕和鼠标轮询率。

## 轨迹绘制优化验证（2026-10-11）

- [ ] 高轮询率鼠标绘制时保持跟手，停在同一点或轻微抖动不会闪烁提示。
- [ ] 单行、多行和 emoji 名称在提示移动、文字长度变化、鼠标穿过屏幕边缘时完整显示，旧文字和轨迹没有残影。
- [ ] 双屏上下、左右或负坐标排列时，跨屏线段连续；没有轨迹经过的显示器不显示空白浮层。
- [ ] 松开、Esc、切换桌面、休眠时轨迹立即消失；下一笔不会出现上一笔内容。

隔离 AppKit 位图测试：局部刷新与整屏刷新在 12 个场景、1x / 2x 两种缩放下逐像素一致，共 52 项检查；包含多行提示移动、缩短、清空、屏幕边缘和跨屏线段。800 × 600 点画布上的短轨迹样例刷新约 9,900 平方点，约为整屏面积的 2.1%。重复位置事件测试中，100 次事件不排队额外识别或绘制。以上是受控样例与事件行为验证，不代表真实显示器功耗或电池续航测量。实机多屏和高轮询率体验仍按上述清单验证。
