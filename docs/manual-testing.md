# 手动验收清单

当前尚未执行以下真机验收。请在 Intel 和 Apple Silicon Mac 上分别记录 macOS 版本、应用版本和结果。

## 安装与权限

- [ ] Universal 二进制包含 arm64 / x86_64，并在两类 Mac 上原生启动。
- [ ] 从 GitHub 下载并安装的 `.app` 在未授权、已授权和已有配置三种情况下均能显示设置窗口，启动时不会崩溃。
- [ ] 首次启动未授权时有明确引导，普通鼠标操作不受影响。
- [ ] 授予辅助功能后自动开始监听；撤销权限后停止并展示正确状态。
- [ ] 关闭设置窗口后菜单栏仍可重新打开设置、暂停、恢复和退出。
- [ ] 重启应用后保留开关、绑定、快捷键、最短长度、轨迹开关和排除应用。

## 鼠标与识别

- [ ] Finder、Safari 和文本编辑器的普通右键点击仍弹出菜单；轻微抖动不触发手势。
- [ ] 自行录制的直线、二至四段折线均可识别，长短 / 快慢绘制行为一致。
- [ ] 斜线、圆圈、乱划和短拖拽不关闭窗口，也不弹出菜单。
- [ ] 绘制时有轨迹和目标操作预览，松开后覆盖层消失。
- [ ] Esc、其他按键或左键取消；之后右键立即恢复正常。
- [ ] 先按 Option 再按右键时，整个右键拖拽过程保持原生行为。
- [ ] 排除的前台应用完全保持原生右键行为。
- [ ] 绘制期间切换应用、暂停、进入睡眠或切换登录用户，不执行过期动作。

## 功能列表与手势录制

- [ ] 列出六类共 60 项常用功能，新用户各项显示“录制手势”，旧用户已有绑定保留。
- [ ] 功能、快捷键、手势在一行按顺序显示，已录制手势以箭头显示，点击可以重录。
- [ ] 搜索与分类能筛选功能；切换筛选会取消未保存的录制并恢复监听，无匹配时有明确提示。
- [ ] 内置功能快捷键为只读文本，点击不会进入录制或修改配置；自定义快捷键仍可录入和编辑。
- [ ] 关闭窗口行显示“窗口关闭按钮”；访达功能在其他应用中不执行并提示先切换访达。
- [ ] 各功能均可在录制区域按住右键绘制、预览、保存，录制期间不触发系统动作。
- [ ] 重复手势提示占用的功能并禁止保存；短轨迹、斜线、超出录制区域的轨迹不能保存。
- [ ] 重新录制后旧手势失效，清除后不再触发，重启后保留结果。
- [ ] Esc、取消按钮、关闭窗口、切换应用取消录制，保留原绑定并恢复正常监听。
- [ ] 鼠标手势录制与键盘快捷键录制互斥，切换录制功能不残留上一次的待保存结果。
- [ ] 暂停手势或未授权时仍可录制；启用并授权后能正常触发已保存的手势。

## 自定义功能

- [ ] 没有自定义功能时，“自定义”默认显示一个空白行，标题最右侧“＋”可连续追加行，默认空白行不暂停监听。
- [ ] 多行分别录入快捷键和手势，切换行不串写；保存或取消某行保留其他草稿，已有自定义功能时，全部保存或删除空白草稿后不再补回空白行；重开设置和重启应用也不会补回。
- [ ] 删除全部已保存自定义功能后，若没有其他草稿，恢复一个默认空白行。
- [ ] 新增和编辑区域按“名称输入框、快捷键、手势、保存”单行显示，列宽与下方列表一致；浅色、深色及最小窗口宽度下无裁切。
- [ ] 点击手势才展开画板，成功后收起并在行内显示；冲突或无效轨迹保留画板并提示，可重新绘制。
- [ ] 编辑中的每行最右侧只有“保存”和“删除”两个文字按钮，最小窗口宽度下文字完整可见，不显示省略号；填写名称、录入软件快捷键、录制手势后才能保存，保存前不触发、不改写旧配置；“删除”仅放弃该行草稿。
- [ ] 保存后自动显示自定义分类，名称、快捷键、手势在同一行，重启后保留。
- [ ] 自定义与内置功能之间、两个自定义功能之间的重复手势均禁止保存，提示占用者。
- [ ] 同名自定义功能、空名称、缺少快捷键或无效手势不能保存。
- [ ] 编辑修改名称、快捷键和手势后保存，旧手势失效；取消和切换窗口不会改写原配置。
- [ ] 清除手势保留名称与快捷键；删除移除条目与绑定；重置清除手势但保留自定义名称和快捷键。
- [ ] 测试目标软件的普通快捷键及全局快捷键；手势提示和最近操作显示自定义名称，录制期间不发送快捷键，结束后恢复监听。
- [ ] 保持目标软件运行，录入其全局快捷键时不触发目标功能，松开主键后显示正确组合；长按只录入一次。
- [ ] 取消、切换窗口、关闭设置和切换录制行后键盘恢复正常；未授权或拦截器创建失败时提示失败，不假装开始录制。
- [ ] 单独 Esc 取消快捷键捕获；带修饰键的 Esc 和 F13–F20 可以录入；退出编辑后普通键盘输入正常。

## 系统动作

- [ ] 创建两个以上桌面，左右切换正常；位于边缘时不触发其他动作。
- [ ] 显示桌面、调度中心在系统快捷键匹配时可触发。
- [ ] 修改系统快捷键后，在应用中重新录制可以恢复对应操作。
- [ ] Safari 多标签页中，关闭标签页只关闭当前标签页。
- [ ] 关闭窗口操作针对当前前台窗口，不退出整个应用。
- [ ] 未保存文稿保留系统保存确认；未暴露关闭按钮的应用显示错误。
- [ ] 切换前台应用后不关闭新的应用窗口。

## 屏幕与界面

- [ ] 多显示器左右 / 上下排列、负坐标、不同缩放比例下，轨迹与鼠标一致。
- [ ] 全屏应用、不同 Space 中轨迹可见，不抢焦点、不截获鼠标点击。
- [ ] 深浅色模式、VoiceOver、键盘 Tab 导航、设置窗口缩放正常。
- [ ] 休眠唤醒、锁屏返回后，右键不会被卡住，轨迹覆盖层不会残留。
- [ ] 长时间绘制和高轮询率鼠标下无明显卡顿，普通右键菜单行为可接受。
